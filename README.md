# 🦋 织梦者

SillyTavern 的优化与工具集合。一个扩展多模块,每个模块独立开关,哪项出问题单独关掉就行,不影响别的。

作者:@不如就叫我道长吧

## 它能做什么

面板分两大类。

### ⚡ 酒馆优化

- **开屏减负**:量清楚酒馆开屏到底吞了多少东西、谁占的、归档能省多少,然后一键把用不到的预设归档进子目录,随时能还原。只读体检不动任何文件,搬不搬你说了算。
- **插件减负**:按体积列出所有扩展并批量开关。酒馆自己的扩展面板能开关,但不告诉你每个多大,所以没人知道该关谁。关掉的扩展代码根本不会被下载,文件和设置都还在。
- **推荐设置**:把酒馆自带、但藏得很深的几个旋钮翻出来摆在明处,点一下就改好。全是原生设置,没打任何补丁。
- **卡顿优化**:十来个独立开关,包括自定义 CSS 输入框防抖、预设条目开关防抖、关代码高亮、折叠代码块、滑动防误触、正则不重载聊天、保存状态小球、保存排队合并、开局请求抢跑等。

### 🧩 我的插件

一键安装和更新作者做的其它插件,不用自己找地址、自己解压。

## 安装

酒馆里点「扩展」→「安装扩展」,粘这个地址:

```
https://github.com/DaoZhang-AI/zhimengzhe
```

装完**刷新一次页面**,插件代码是开页面时才加载的。

打开方式有两个:输入框左边的魔杖菜单里有一项,或者扩展设置面板最上面。

## 服务端插件(可选)

**归档功能需要它,其它功能没有它照样能用**,探不到会自动降级,只是不显示归档按钮。

为什么需要:酒馆自带的接口会把路径分隔符过滤掉,浏览器侧写不进子目录,归档这个动作只能在服务端做。

装法:

1. 把本仓库里的 `server-plugin` 文件夹复制到酒馆根目录的 `plugins/` 下,**并改名为 `zhimengzhe`**,最终是 `plugins/zhimengzhe/index.js`
2. 打开酒馆根目录的 `config.yaml`,把 `enableServerPlugins` 改成 `true`
3. 重启酒馆

装好之后面板里会多出归档按钮。

## 一个顺带的发现

酒馆自带请求压缩,但**默认是关着的**。在 `config.yaml` 里把 `requestCompression.enabled` 改成 `true` 再重启,保存设置的体积能降到四分之一左右。如果你用的是远程部署加隧道,这一项的收益比本插件所有优化加起来都大。面板里的「推荐设置」会检测并提示。

## 兼容

- 需要较新版本的 SillyTavern
- 只用酒馆自己的公开接口,不修改酒馆本体任何文件
- 卸载或禁用后,所有改动自动失效,不留残留
